# Badge images

GitHub's achievement artwork is © GitHub, Inc. To respect that, this repository
**does not copy** the images. Pages load them directly from GitHub's own asset server.

## URL pattern

```text
https://github.githubassets.com/images/modules/profile/achievements/<slug>-<tier>.png
```

- `<tier>` is `default`, `bronze`, `silver` or `gold` (tiers only exist for multi-level badges).
