# 🚀 Getting started with GitHub Achievements

## Where achievements appear

Achievements are shown in the **left sidebar of your profile**
(`https://github.com/<your-username>`). Hover or click a badge to see a short
description and links to the events that earned it. Event links are only visible to
people who have access to the related repository.

Source: [Profile reference — GitHub Docs](https://docs.github.com/en/account-and-profile/reference/profile-reference)

## Make sure they are visible

| Setting | Where | Effect |
| --- | --- | --- |
| **Show Achievements on my profile** | Profile picture → **Settings** → *Profile settings* → **Update preferences** | Shows or hides all achievements |
| **Hide from profile** (per badge) | Your profile → click a badge → eye icon | Hides one badge from others |
| **Private contributions** | Your profile → **Contribution settings** (above the contribution graph) | Shows anonymised private activity |
| **Private profile** | Settings → *Public profile* | Hides achievements and highlights from everyone else |

Sources: [Manage visibility settings for private contributions and achievements](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements) ·
[Setting your profile to private](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/setting-your-profile-to-private)

## Prerequisites

1. A GitHub account with a **verified email**.
2. Git configured with an email linked to that account:

   ```bash
   git config --global user.name "Your Name"
   git config --global user.email "<id>+<username>@users.noreply.github.com"
   ```

   See [Setting your commit email address](https://docs.github.com/en/account-and-profile/how-tos/email-preferences/setting-your-commit-email-address).

3. Optional but handy: the [GitHub CLI](https://cli.github.com/), then `gh auth login`.

## A realistic first week

| Day | Activity | Badges it can lead to |
| --- | --- | --- |
| 1 | Create a personal project repo with a README ([Hello World](https://docs.github.com/en/get-started/start-your-journey/hello-world)) | — |
| 2 | Improve your README in a branch and merge the PR yourself | YOLO, progress toward Pull Shark |
| 3 | Close an issue you opened by mistake or as a duplicate | Quickdraw |
| 4 | Fix a typo or doc issue in a project you use | Pull Shark |
| 5 | Pair with a friend on a change, using `Co-authored-by` | Pair Extraordinaire |
| 6–7 | Answer questions in GitHub Discussions | Galaxy Brain |

Starstruck and the higher tiers come from **months of consistent, useful work** — that is the point.
