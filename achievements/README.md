## What GitHub officially documents

GitHub Docs states that:

- "Achievements celebrate specific events and actions that happen on GitHub" and appear as badges in the profile sidebar.
- Hovering or clicking a badge shows a detailed view with a short description and links to the events that earned it.
- The feature is **in public preview and subject to change**.
- You can hide all achievements, hide individual ones, and choose whether private contributions count.
- The Mars 2020 Helicopter Contributor event has ended and the badge is no longer available.

Source: [Profile reference](https://docs.github.com/en/account-and-profile/reference/profile-reference) ·
[Manage visibility settings](https://docs.github.com/en/account-and-profile/how-tos/contribution-settings/manage-visibility-settings-for-private-contributions-and-achievements)

GitHub **does not** publish the exact triggers or tier thresholds for individual
badges. Everything in the requirement columns above is therefore labeled 🧪.

## Tutorial format

Every tutorial in this folder follows the same structure:

1. What the achievement represents
2. Requirements (with status labels)
3. Step-by-step instructions with real Git / `gh` commands
4. How to check whether it was awarded
5. Restrictions and gotchas
6. Sources
