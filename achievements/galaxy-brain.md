## 1. What it represents

Galaxy Brain recognises helpful people: your reply in a
[GitHub Discussion](https://docs.github.com/en/discussions/quickstart) was **marked as the answer**.

## 2. Requirements

| Tier | Accepted answers | Status |
| --- | :---: | :---: |
| Base | 2 | 🧪 |
| Bronze (`x2`) | 8 | 🧪 |
| Silver (`x3`) | 16 | 🧪 |
| Gold (`x4`) | 32 | 🧪 |

| Detail | Status |
| --- | :---: |
| Answers can only be marked in a discussion category that accepts answers (for example **Q&A**) | ✅ ([Docs](https://docs.github.com/en/discussions/collaborating-with-your-community-using-discussions/participating-in-a-discussion)) |
| The discussion author or a maintainer marks the answer | ✅ (same page) |
| Answering your own question does not count | ❓ |

## 3. Step by step

### Step 1: Find questions you can answer

- [GitHub Community discussions](https://github.com/orgs/community/discussions) (Q&A categories)
- The **Discussions** tab of tools you use every day
- Filter for unanswered questions: on a repository's Discussions page, choose the Q&A category and sort by newest or filter to *Unanswered*.

### Step 2: Write a high-quality answer

A good accepted answer usually:

1. Restates the problem in one sentence.
2. Gives the fix with a minimal, tested code sample.
3. Explains **why** it works.
4. Links to official documentation.

```markdown
You're seeing this because `actions/checkout` fetches only one commit by default.
Set `fetch-depth: 0` to fetch the full history:

    - uses: actions/checkout@v4
      with:
        fetch-depth: 0

Docs: https://github.com/actions/checkout#usage
```

### Step 3: Follow up

If the author replies with more detail, update your answer. Authors mark an answer
when it actually solves their problem — you cannot mark your own reply as the answer on someone else's question.

See the [GitHub Discussions guide](../guides/github-discussions.md) for more tips.

## 4. Check whether it was awarded

- Your answer shows a green **Answered** check in the discussion.
- After two accepted answers, check your profile's **Achievements** section.

## 5. Restrictions and ethics

- ❌ Do not ask friends to post questions just so you can answer them.
- ❌ Do not post AI-generated answers you have not verified.
- ✅ Being genuinely helpful is the only reliable way to reach higher tiers.
