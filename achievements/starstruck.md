## 1. What it represents

Starstruck is awarded when a repository **you created** is starred by many people.
Stars are how GitHub users bookmark and show appreciation for projects
([Saving repositories with stars](https://docs.github.com/en/get-started/exploring-projects-on-github/saving-repositories-with-stars)).

## 2. Requirements

| Tier | Stars on one repository | Status |
| --- | :---: | :---: |
| Base | 16 | 🧪 |
| Bronze (`x2`) | 128 | 🧪 |
| Silver (`x3`) | 512 | 🧪 |
| Gold (`x4`) | 4096 | 🧪 |

| Detail | Status |
| --- | :---: |
| Stars must be on a repository you own/created (not a fork you made of someone else's project) | 🧪 |
| Stars are counted per repository, not summed across repositories | 🧪 |

## 3. Step by step — earning stars honestly

There is no shortcut. Projects get stars when they are **useful and easy to discover**.

1. **Solve a real problem.** Tools, templates, learning resources and curated lists do well.
2. **Write a great README** — what it does, a screenshot or GIF, quick-start, license.
3. **Add topics** so people can find it:

   ```bash
   gh repo edit --add-topic cli --add-topic productivity --add-topic open-source
   ```

4. **Add a clear description, a license and a contribution guide** so people can find
   the project and feel safe using and improving it:

   ```bash
   gh repo edit --description "A short, searchable description of the project"
   ```

5. **Share it where it is relevant** — a blog post, a talk, a community forum —
   following each community's self-promotion rules.
6. **Keep it maintained**: answer issues, merge good PRs, publish releases.

Check your star count any time:

```bash
gh repo view <you>/<repo> --json stargazerCount --jq .stargazerCount
```

## 4. Check whether it was awarded

Once a repository you created passes 16 stars, look for Starstruck on your profile.
Higher tiers replace the displayed badge with the highest level reached.

## 5. Restrictions and ethics

> [!CAUTION]
> Buying stars, star-for-star exchanges, or using multiple accounts to star your own
> projects is **inauthentic activity** and is prohibited by the
> [GitHub Acceptable Use Policies](https://docs.github.com/en/site-policy/acceptable-use-policies/github-acceptable-use-policies).
> GitHub can remove fake stars and take action against accounts.
