# 🗄️ Other achievements and badges

Badges that **cannot currently be earned** through everyday activity, plus profile
**highlights** that are often confused with achievements.

published** how to earn them and they are not reliably awarded.

## Profile highlights (not achievements)

These appear in the **Highlights** area of a profile. They reflect membership or a
subscription rather than activity, and GitHub Docs lists them separately from achievements.

| Highlight | How you get it |
| --- | --- |
| **PRO** | Subscribe to GitHub Pro. Disappears if the subscription ends. |
| **Developer Program Member** | Register for the GitHub Developer Program. |
| **Security Bug Bounty Hunter** | Have a valid report accepted by the GitHub Security Bug Bounty. |
| **GitHub Campus Expert** | Be accepted into the GitHub Campus Expert program. |
| **Security advisory credit** | Be credited on a security advisory published in the GitHub Advisory Database. |

Source: [About your profile — GitHub Docs](https://docs.github.com/en/account-and-profile/concepts/personal-profile) ·
community reference [drknzz/GitHub-Achievements](https://github.com/drknzz/GitHub-Achievements)
