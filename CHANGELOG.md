## [1.0.0] - 2026-11-08

### Added

- README with achievement gallery, tier table, FAQ and progress tracker.
- Tutorials for all seven currently earnable achievements: Quickdraw, YOLO, Pull Shark,
  Pair Extraordinaire, Galaxy Brain, Starstruck and Public Sponsor.
- `other-achievements.md` covering retired badges (Arctic Code Vault Contributor,
  Mars 2020 Helicopter Contributor), unreleased badges (Heart On Your Sleeve,
  Open Sourcerer) and profile highlights.
- Guides: getting started, profile optimization, open-source contributions,
  GitHub Discussions, common mistakes, progress tracker.
- Requirement status labels (✅ Official · 🧪 Community-reported · ❓ Unverified).
- Contribution guide, Code of Conduct, Security policy, issue forms and PR template.
- GitHub Actions: Markdown lint, documentation validation, link checking, PR checks.
